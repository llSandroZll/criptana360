# Communication Language Rule

You MUST always communicate with the user in English.

1. **User Communication**: All explanations, strategies, responses, questions, code reviews, and messages directed to the user must be written in English.
2. **Deliverables & Scripts**: When generating short-form video scripts or voiceover copy intended for the local Spanish audience as specified in `TIKTOK_PLAYBOOK.md`, the voiceover column itself remains in natural Spanish, but all surrounding direction, explanations, and advice must be in English.
